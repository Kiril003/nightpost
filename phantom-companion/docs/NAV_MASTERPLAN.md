# PHANTOM NAV — МАЙСТЕР-ПЛАН «НАВІГАЦІЙНИЙ ОРГАНІЗМ»

> Навігація глибша за Waze/Google/Apple: максимум з OpenStreetMap (пішки/вело/авто/мультимодал + транспорт),
> серйозний аналіз маршрутів для водія, досьє будь-якого місця одним тапом, маршрут ВСЕРЕДИНІ 3D Crystal City,
> жива розмова з PHANTOM під час руху.
>
> Дочірній план `MAP_MASTERPLAN.md` — успадковує його **9 законів живої мапи** (орган-не-вкладка, подвійне
> керування, чесність, keyless-first, офлайн-виживання, проактивність за згодою, адаптивність, одна лінза
> правди, розкриття за глибиною). Поглинає та деталізує M-B/D і частини M-A/E/K.
> Живий стан — секція NAV у `MAP_MASTERPLAN_PROGRESS.md`.

---

## 0. КОНТЕКСТ

Оператор попросив навігаційну систему потужнішу і продуманішу за мейнстрім-мапи: викрутити максимум з OSM,
глибокий аналіз маршрутів (варіанти в деталях, загрози, камери, патрулі), інформаційні можливості по кожному
місцю (з іконкою чи без), повну інтеграцію розуму PHANTOM, 3D-ефекти, яких не має жодна мапа, і повний
редизайн організації елементів — «зручно і неймовірно красиво».

Рішення оператора (2026-07-09):
- **Перша фаза — редизайн-оболонка UI** (сцени), решта фаз лягають у неї.
- **Патрулі**: живого безкоштовного фіда НЕ існує (Waze бере з власного натовпу) → чесний шлях:
  ручні мітки оператора/PHANTOM з TTL ~2 год + камери швидкості з OSM як надійний шар. Жодних фейкових даних.

## 2. ФАЗИ

### NAV-0 — СЦЕНИ (редизайн-оболонка) ✅ поточна сесія
Одне полотно, три стани хрому (`MapSceneState`):
- **CALM** — мапа + орб + кругла ← + одна нижня **command pill** (пошук · «Спитай або шукай…» · мікрофон).
  Пігулка тривоги — лише під час тривоги. Більше нічого (закон 9, M-K08).
- **EXPLORE** — вхід: тап/довгий тап/пошук/поруч/пуш PHANTOM. Один скляний **sheet host**
  (peek/half/full) з контекстним вмістом: дії точки, «поруч», згодом порівняння маршрутів і досьє.
  Рейл шарів праворуч: згорнутий орб → тогли + легенда (M-K12).
- **GUIDE** — рамка навігації: верхній слот маневр-банера, нижній слот ETA-стрічки (наповнює NAV-2;
  зараз сюди переїжджає RouteBanner — активний маршрут стає режимом, а не плаваючим клаптем).

Command pill = «розмова з мапою»: тап → пошук (Nominatim), мікрофон → PTT до PHANTOM з gaze-контекстом.
Рефактор: `ui/map/scene/` — `MapSceneState` / `MapCanvas` (стиль-пайплайн `mapStyleStep` переїздить
дослівно) / `MapChrome` / `CommandPill` / `SheetHost` / `LayerRail`; `MapScreen` → тонка композиція.
Поглинає M-K07/K08/K12.

### NAV-1 — ГЛИБИНА МАРШРУТІВ
- `OsrmClient` повний: `steps=true&alternatives=true&annotations=true`, waypoints (перетяг — M-B05).
- **RouteIntel** — аналізатор коридору: семпли вздовж полілінії → Overpass-збагачення (клас дороги,
  покриття, освітлення, maxspeed, `highway=speed_camera`), профіль висоти (open-elevation),
  перетини з активними шарами (тривога/радар/укриття).
- Порівняння варіантів пліч-о-пліч у sheet: час/відстань/повороти/склад доріг/камери/висота.
- **Hook:** `route.compare`, розширений `map.route` зі steps. Поглинає M-B02/B03/B05/B11/B13.

### NAV-2 — ЖИВИЙ СУПРОВІД
- Машина станів Idle→Preview→Guiding→Arrived; map-matching до полілінії; off-route → авто-перемаршрут.
- Камера-переслідування bearing-up + нахил; маневр-банер зі стрілкою і відліком; TTS українською (core-voice).
- Швидкість + ліміт OSM + м'яке попередження перевищення.
- **`NavigationSnapshot` у shared gaze** — оператор говорить з PHANTOM посеред руху, PHANTOM бачить
  крок/ETA/швидкість. **Hook:** `nav.start` / `nav.stop`. Поглинає M-B04/B15. WorkManager для живучості.

### NAV-3 — 3D-СТРІЧКА (вау, якого нема ні в кого)
- Сяюча анімована стрічка маршруту у Filament серед кристалічних будівель (пульс біжить уздовж).
- Кінематографічний прев'ю-обліт маршруту перед стартом (reuse focusRequests + крива камери).
- Будівлі впритул до стрічки деликатно прозорішають. Поглинає напрям M-K03/M-N06.

### NAV-4 — ДОСЬЄ МІСЦЯ (тап у будь-що)
- POI: теги OSM красиво (відкрито/зачинено наживо з opening_hours, телефон, кухня, доступність),
  Wikipedia/Wikidata витяг + фото Wikimedia, «схоже поруч».
- Порожнє місце: reverse-geocode + Overpass around + **картка будівлі з даних Crystal City**
  (поверхи, тип, адреси).
- AI-огляд PHANTOM у картці. **Hook:** `place.info`. Поглинає M-A03/E07/E08/E09/E10.

### NAV-5 — ШАР ЗАГРОЗ ВОДІЯ
- Камери швидкості з OSM (Overpass, keyless) — шар + попередження наближення.
- **Ручні мітки патрулів/блокпостів** (оператор пальцем або PHANTOM з чату) з TTL ~2 год —
  тьмяніють і зникають; чесна відсутність замість фейкового натовпу (рішення оператора).
- Двигун попереджень у русі: камера попереду / мітка попереду / в'їзд у область тривоги.
  Поглинає M-B07/B08, споріднений M-G05.

### NAV-6 — ТРАНСПОРТ УГЛИБ
- Тап зупинки → лінії/напрямки через OSM route relations; візуалізація лінії на мапі.
- Підключення GTFS-RT до міст, де фід є (чесно «нема» де нема); «додому громадським» одна дія.
- Мультимодальні евристики (пішки→транспорт→пішки); OTP self-host — стретч.
  Поглинає M-D02/D03/D07/D13.

## 3. АРХІТЕКТУРНІ ПРАВИЛА

1. Нові дані = тонкий suspend-клієнт у `core-net/.../map/` за зразком `OverpassClient`; мовчазне джерело
   ніколи не блокує мапу.
2. Кожна здатність = tool-verb для PHANTOM + жест для оператора (один код-шлях).
3. Все просторове = `SpatialLayer` у спільному стеку; ніяких нових екранів.
4. Схеми інструментів — через Gemini-адаптер (інакше cloud 400).
5. Фонове, що мусить пережити kill — WorkManager.
6. Файли < 500 рядків; сцена-компоненти замість монолітів.
7. Кожен шар має чесний стан «даних немає».
