# Симбіоз мапи і месенджера — вказівник на контракт

**Канонічний документ:** `phantom-os-messenger/docs/GEO_SYMBIOSIS_CONTRACT.md`
(гілка `feat/messenger-core`). Тут — НЕ копія: дві правди дрейфують. Правки —
лише в канон, через месенджер-сесію.

Статус: погоджено обома сесіями 24.08.2026 (наказ власника про повний симбіоз).

## Що з контракту тримає мапа (шпаргалка виконавця)

- `PeerPoint` у core-data (`StateFlow`, батчем): nodeId, name, lat/lon, `atMs` =
  час ВИМІРУ, accuracyM?, verified, share (ONE_SHOT|LIVE|TRAIL + expiresAtMs),
  `seq` (дірка в seq — єдине чесне джерело розриву сліду), `threadId`, etaHint?.
- ЧИСТОТА ДОМЕНУ: repository — гола поверхня обміну. Жодних месенджерних типів
  у core-data (ні MessengerMessage, ні client_id, ні сесій) і жодних мапних
  (ні тайлів, ні стилю). Месенджер кладе PeerPoint — мапа читає. Крапка.
- Фігурки людей — окремий шар движка. Звірений → суцільна, незвірений → контурна
  (форма, не лише колір). Свіжа = atMs ≤ 90с І seq без дірки; інакше застаріла —
  приглушена + «станом на HH:MM». Точка зі скриньки народжується застарілою завжди.
- Чужу точку НЕ інтерполюємо (коустинг — лише про себе); розрив тіків = розрив
  пунктиром. Жодна чужа точка не стає ключем зовнішнього запиту — локальні
  паки або чесна порожнеча.
- Іменовані контакти ≠ анонімна краудова площина `live_marks`. Не змішувати.
- `routeSummary(lat, lon)` → {distanceM, durationS, register} на вузлі
  ОДЕРЖУВАЧА; register дослівно в бульбашку («орієнтовний» для dev/офлайн).
  Хвиля 3: опційний profile (drive/walk), дефолт підказує режим сцени.
- `geo:mark.kind` — лише сім класів пера: gate/checkpoint/patrol/crash/camera/
  shelter/danger; некласифіковане не їде взагалі.
- Міні-карта в стрічці — статичний знімок рендеру (закон D1, другої живої
  поверхні нема). Тап → повна мапа.
- Приймання кожної хвилі — часовим рядом + порожній мережевий журнал під час
  показу чужої точки.

Мапний бік стику стартує окремим валом після ATLAS-2. Черга хвиль: точка живе →
живий шерінг з TTL → маршрут і зустріч → група і тривога (збір в укриття через
SceneMode.THREAT).
