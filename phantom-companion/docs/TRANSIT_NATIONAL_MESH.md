# TRANSIT NATIONAL MESH — національний міжміський граф, офлайн

Статус: архітектура затверджена цим документом; Фаза 0 (див. нижче) вже
збудована. Мета: оператор сідає на тролейбус у Києві, пересідає на
міжміський потяг, виходить на зупинці у Львові — **все сплановано офлайн,
на телефоні, одним RAPTOR-запитом.**

## Принципи (успадковані, непорушні)

1. **Жодного бекенда.** Граф живе в асетах/на диску телефона. RAPTOR над
   плоскими масивами; жодного OTP/Valhalla.
2. **Часи МОДЕЛЬОВАНІ й кажуть про це.** Укрзалізниця не публікує вільного
   GTFS; розклади міняються. Ми возимо топологію + геометрію (міняються
   рідко) і частотну модель (чесне «приблизно кожні N годин»), кожен ride —
   `timesAreModelled`. Ніколи не показуємо модельовану хвилину як обіцянку.
3. **Одна уніформа даних.** Кожне джерело (місто, метро, залізниця)
   компілюється в ті самі `RawStop`/`RawTrip`/`RouteShape` і зливається
   одним `TimetableBuilder.build()`. Солвер не знає слова «міжміський».

## Шардинг: місто = шард, залізниця = хребет

```
assets/
  kyiv_surface.json     ← шард міста (bus/trolley/tram, shapes)
  kyiv_metro.json       ← метро (як зараз)
  lviv_surface.json     ← наступні міста, той самий скрипт
  rail_ua.json          ← ХРЕБЕТ: train-реляції admin_level=2 (вся Україна)
```

- Кожен шард генерує **той самий** `scripts/fetch_surface_transit.py`
  (місто більше не захардкоджене): `--area Львів`, `--area Харків`…
- Хребет: `--area Україна --admin-level 2 --modes train --min-stops 4`.
  OSM route=train реляції несуть і колії (shapes), і станції-зупинки.
  Headway-модель поїздів навмисно консервативна (peak 2 год / day 3 / eve 4).
- Розмір: шард міста ≈ 0.6–1.2 МБ, хребет ≈ 2–4 МБ полілайн5. Убюджеті.

## Злиття на пристрої (Фаза 1 — наступна сесія)

`TransitRepository` (де сьогодні зливаються metro+surface) отримує список
шардів замість пари:

```
fun fuse(shards: List<SurfaceDoc>, metro: MetroFeed): Timetable
```

- Стопи дедуплікуються по OSM id (`s{node}` глобально унікальні).
- Пересадки місто↔залізниця виникають БЕЗКОШТОВНО з proximity-footpaths
  TimetableBuilder-а: зупинка «Вокзальна» стоїть за 180 м від станції
  Київ-Пас. — це вже пересадка. Единий тюнінг: `maxTransferMeters` для
  залізничних станцій підняти до 400 м (вокзал більший за перехрестя).
- Ліниве завантаження: шард міста відкривається, коли origin/destination
  падає в його bbox (зберігати bbox у SurfaceDoc); хребет — завжди.
  Пам'ять: Київ+Львів+хребет ≈ 3–5 МБ heap у Timetable-масивах — тримаємо.

## Що НЕ робимо (чесність)

- Не синтезуємо приміські електрички без перевірки покриття OSM (реляції
  нерівні по областях) — спершу заміряти, потім обіцяти.
- Не показуємо міжміський ETA точніше ніж «~N год» поки часи модельовані.
- Автобусні міжміські маршрути (route=bus між містами) — Фаза 2, після
  заміру якості реляцій; вони найбрудніші в OSM.

## Фаза 0 — ЗБУДОВАНО (ця сесія)

- Інжест city-agnostic: `--area/--admin-level/--modes/--min-stops/--out`,
  фізична геометрія з way-членів реляцій (збірка ланцюга з орієнтацією,
  розриви > 60 м рахуються, > 8 розривів = чесно без shape), проєкція
  зупинок на shape (монотонна, медіана > 150 м = shape відкинуто),
  polyline5, hopSeconds з реальної довжини колії.
- Рантайм: `SurfaceLine.shape/stopShapeIdx` → `RouteShape` → RawTrip →
  `Timetable.routeShape` + `shapeBetween()`; Ride.points = реальна колія.
- Піші legs: OSRM foot → офлайн-фолбек LocalRouter над постійною
  дорожньою сіткою (RoadMeshStore) — хід не літає крізь будинки.
- Рендер: стрічка розшита на шари — ride суцільний у кольорі ЛІНІЇ з
  фіда (casing під ним), walk пунктиром, вузли посадки/пересадки/виходу —
  тапабельні кола (place-card з назвою зупинки і дією).
- `TransitMode.RAIL` вже існує в enum і в рендер-палітрі — хребет ляже
  без жодної зміни рантайму.

## Порядок наступної сесії

1. `python3 scripts/fetch_surface_transit.py --area Україна --admin-level 2
   --modes train --min-stops 4 --out core-data/src/main/assets/rail_ua.json`
   → заміряти розмір/якість (скільки shaped, скільки станцій).
2. TransitRepository: fuse(List<SurfaceDoc>) + bbox у SurfaceDoc + ліниві
   шарди + `maxTransferMeters` 400 для RAIL-станцій.
3. Львів як другий шард; device QA маршруту Київ(зупинка)→Львів(зупинка)
   в airplane mode.
