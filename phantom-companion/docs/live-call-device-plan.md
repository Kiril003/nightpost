# «Подзвонити PHANTOM» — план перевірки на апараті

Юніт-тести (`core-voice/.../live/*Test.kt`) доводять те, що належить телефону:
машину станів, ворота згоди, стенограму, звідки рахується «кінець мови» і що
звук іде в динамік із першим шматком. Мережу, модель, AEC і реальну затримку
доводить лише апарат. Цей план — для лідера на A52 (або іншому телефоні).

## Що поставити перед прогоном

- APK `fieldDebug` з гілки `cloud/sym-live-call` (після sync бандла лідером).
- Спарений ПК із ключем Gemini у `config.ai_gemini_api_key` (шлях А) **або** ключ
  Gemini, вписаний на телефоні в налаштуваннях розуму (шлях Б).
- Moonshine tiny-uk і Supertonic 3 завантажені на телефон (для покрокового режиму).
- `adb logcat -s PhantomCall LiveCallAudio OkHttp` у сусідньому вікні.
  Адреса сокета містить токен — у лог вона не пишеться і не має писатись.

## 1. Живий шлях

| # | Дія | Очікування |
|---|---|---|
| 1.1 | Чат PHANTOM → кнопка дзвінка | Накладка над домівкою, «Живий голос», «Зʼєдную» → «Слухаю» менш ніж за 2 с |
| 1.2 | «Привіт, як мене звати?» | Відповідь українською голосом; субтитри «Ви: …» і репліка PHANTOM; кільце дихає з голосом |
| 1.3 | Перебити посеред довгої відповіді | PHANTOM стишується одразу (локальний край мови), замовкає за ≤ 300 мс після `interrupted`, слухає |
| 1.4 | Говорити на гучномовці при максимальній гучності | PHANTOM не перебиває сам себе (AEC). Якщо перебиває — записати модель апарата: `echoCancelled` у LiveCallAudio |
| 1.5 | «Що ти памʼятаєш про мою сестру?» | Виклик `memory_recall`, відповідь з памʼяті або «нічого немає» — не вигадка |
| 1.6 | «Де найближча аптека?» | `map_lookup` → `spatial.search`, відповідь з мапи |
| 1.7 | «Що мені писала Марта?» | `messages_read`, останні листи |
| 1.8 | «Напиши Марті, що я запізнюсь» | Картка «Кому: Марта. Текст: … Надсилати?»; лист НЕ пішов. «Так» голосом → лист у розмові з Мартою. Повторити з «ні» та з кнопками «Так/Ні» |
| 1.9 | «Подзвони телефоном» (phone.ring) при драбині «Звук» = «Бачити» | Відмова словами драбини. При «Робити з так» — картка згоди |
| 1.10 | Мікрофон вимк. / динамік / субтитри | Мікрофон: сервер нічого не чує, кільце стоїть. Динамік: звук іде в слухавку і назад. Субтитри ховаються |
| 1.11 | Завершити | У чаті PHANTOM — репліки дзвінка по черзі, перебиті з «—». Дуплексний слух повертається, якщо був увімкнений |
| 1.12 | Дзвінок довше 15 хв | goAway → «Зʼєдную» на мить → розмова продовжується (той самий контекст, новий токен) |
| 1.13 | Вимкнути Wi-Fi посеред розмови, увімкнути за 3 с | «Зʼєдную», до трьох спроб; якщо не вийшло — «Звʼязок обірвався: … Далі — покроково» |

## 2. Покроковий (деградований) шлях

| # | Дія | Очікування |
|---|---|---|
| 2.1 | ПК без ключа, на телефоні ключа немає → дзвінок | «Покроково», примітка «Живий голос недоступний: на компʼютері не задано ключ Gemini; на телефоні немає ключа Gemini…» |
| 2.2 | Утримати кнопку, сказати, відпустити | «Слухаю» під час утримання → «Думаю» → відповідь голосом Supertonic |
| 2.3 | Без моделі Supertonic | Відповідь текстом на екрані, примітка «Голосу на телефоні немає — відповідь текстом» |
| 2.4 | ПК вимкнений, хмари немає | Чесне «розуму немає» з BrainChain, не тиша |
| 2.5 | Вузький канал (сховок на слабкому звʼязку) | Відповідь текстом, примітка «Вузький канал» |
| 2.6 | Після дзвінка | Обидві репліки кожного ходу — у розмові з PHANTOM, без дублів |

## 3. Затримка: бюджет 800 мс від кінця мови до першого звуку

Що міряється: від останнього гучного кадру мікрофона (так само, як у
`SpeechEdge`) до першого шматка звуку відповіді в динаміку.

1. Телефон сам пише кожен замір: `adb logcat -s PhantomCall` →
   `перший звук за N мс (бюджет 800)`. Це час від останнього гучного кадру до
   першого шматка відповіді, що прийшов у телефон (без буфера динаміка).
2. Обʼєктивний замір (без довіри до коду): записати дзвінок другим телефоном
   поруч, 20 коротких питань («котра година», «як мене звати»). В Audacity
   поміряти відстань від кінця слова людини до першого звуку PHANTOM.
3. Розкласти бюджет:
   - тиша, яку чекає сервер (`silenceDurationMs` = 300);
   - мережа телефон → Google (RTT, `ping generativelanguage.googleapis.com`);
   - перший шматок моделі;
   - буфер AudioTrack (більший із мінімального і 100 мс, `PERFORMANCE_MODE_LOW_LATENCY`).
4. Критерій: медіана ≤ 800 мс, p90 ≤ 1100 мс на Wi-Fi; окремо записати LTE.
   Якщо понад бюджет — спершу `silenceDurationMs` (250), потім розмір буфера.

## 4. Що перевірити окремо

- Версії точок входу Google: ПК карбує токен через `v1beta/auth_tokens`
  (`routes_live_token.py`), телефон відкриває `v1alpha …BidiGenerateContentConstrained`.
  Якщо сокет відповідає 401/403 при живому токені — звірити версію з поточною
  документацією Gemini Live і вирівняти обидва кінці.
- Чи модель `gemini-3.8-live` справді говорить українською з `languageCode: uk-UA`
  (якщо сервер відмовляє через `speechConfig` — прибрати поле, мову тримає персона).
- Ключ ніде не потрапляє в лог: `adb logcat | grep -i AIza` — порожньо.
