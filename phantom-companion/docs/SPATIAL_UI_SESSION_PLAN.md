# PHANTOM Companion — План сесій просторового інтерфейсу (Spatial UI)

Цей документ містить готові точкові промпти для окремих чистих сесій розробника. Кожен промпт містить мінімальний контекст (файли для завантаження) та чіткі інструкції, що запобігає переповненню контексту моделі та економить токени.

---

## 🛠 Модельна матриця (яку модель обрати)

* **Low / Lite (Gemini 3.5 Flash Low)**: для запуску білдів, аналізу логів, написання unit-тестів, фіксів синтаксису чи перейменувань.
* **Medium (Gemini 3.5 Flash Medium)**: основна робоча конячка. Пише Compose-код, верстає інтерфейси, оновлює ViewModel, налаштовує переходи.
* **High / Hard (Gemini Pro / Claude 3.5 Sonnet)**: використовується ТІЛЬКИ коли є складна логіка баз даних, міграції Room, синхронізація WebSocket з потоками чи складні баги з пам'яттю.
